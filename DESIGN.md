# Design

Nick requested ULTRA MINIMAL, Geist Mono and a copy-first hierarchy on November 16, 2026.

Warm white, near-black type and one narrow column. All type is 12–14px. The installation command and Copy button are primary. A small product identifier, Node prerequisite and two source links support that action. No display headline, eyebrow, tagline, cards, gradient, badges or illustration.

Motion uses bounded state feedback: pointer press at 120ms ease-out, scale .97; persistent layered copy/check icons cross-fade and scale over 240ms with a firm ease-out. Keyboard activation remains immediate. Reduced motion removes the transition and scale. No entrance sequence, bouncing icon, spinner or layout animation. Copy uses a familiar duplicate-sheets icon and switches to a checkmark after clipboard success. Its accessible name and live status confirm the outcome without permanent explanatory copy. Clipboard failure displays recovery instructions. Supporting directions match the 13px product identifier; text-size-adjust prevents mobile paragraph inflation. The button has a fixed 44px footprint. Recopy keeps the check visible while pending; one owned 1800ms reset timer restarts on success and is cleared before another attempt and on unmount. Keyboard activation and reduced motion disable icon transitions. No initial animation.
