# Design

Nick requested ULTRA MINIMAL, Geist Mono and a copy-first hierarchy on November 16, 2026.

Warm white, near-black type and one narrow column. All type is 12–14px. The installation command and Copy button are primary. A small product identifier, practical paste guidance, Node prerequisite and two source links support that action. No display headline, eyebrow, tagline, cards, gradient, badges or illustration.

Motion follows emil-ask-emil → emil-animations. Only pointer press feedback on Copy: 120ms ease-out, scale .97. Keyboard activation remains immediate. Reduced motion removes the transition and scale. No entrance sequence, bouncing icon, spinner or layout animation. Copy success changes its label without movement.
