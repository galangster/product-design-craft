# Product design craft

Practical instructions for auditing product UI, creating detailed interfaces and comparing prototype directions.

```sh
npx skills add galangster/product-design-craft
```

Requires Node.js 22.20+. Choose your agent in the installer. Installs in the current project by default. Read [the skill](skills/product-design-craft/SKILL.md), [recipes](skills/product-design-craft/references/patterns.md) and [evidence limits](skills/product-design-craft/references/sources.md).

## Site

`npm install`, then `npm run dev`. Run `npm run check`, `npm run lint`, and `npm run build` before release.

This is original synthesized guidance, not an official or endorsed Kole Jain or Emil Kowalski product. The source notes distinguish partial transcript research from direct visual inspection. No raw transcripts are distributed.

Release setup: set `VITE_SKILL_REPOSITORY` to the verified public `owner/repository`. The verified default is galangster/product-design-craft. No npm package is published.
